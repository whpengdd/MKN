## MODIFIED Requirements

### Requirement: 表格可视化编辑

表格渲染态 SHALL 提供增删行列与列对齐操作,直接改写底层 pipe 文本;操作可被撤销/重做。点击渲染表格的某个单元格 SHALL 把光标精确定位到该单元格对应的 pipe 源码位置(单次点击完成 reveal 与定位),不得统一跳到表格起点、不得要求二次点击。

#### Scenario: 增删行列改写源码

- **WHEN** 在渲染表格的工具条点击增/删行列或切换对齐
- **THEN** 底层 Markdown pipe 表格相应更新,且 `⌘Z` 可回退

#### Scenario: 点击单元格精确定位

- **WHEN** 在渲染态表格点击第 R 行第 C 列的单元格(R 含表头)
- **THEN** 表格 reveal 成源码,光标落在该单元格对应的源码偏移所在行,且不发生竖直方向的行偏移(不会落到相邻行)

#### Scenario: 点击表头单元格

- **WHEN** 在渲染态表格点击表头某列单元格
- **THEN** 光标落在 pipe 源码表头行对应位置,而非分隔行或首数据行

## ADDED Requirements

### Requirement: 块级渲染高度估算

跨多行的块级渲染 widget(表格、块级公式 `$$...$$`、Mermaid 图)SHALL 提供与其所替换源码行数相称的高度估算,使其自身或其上方块在尚未被 CodeMirror 测量时,点击坐标到文档位置的映射不产生竖直方向的行漂移。

#### Scenario: 块上方未测量时点击不漂移

- **WHEN** 文档中某个跨多行块 widget 上方存在尚未测量的同类块,用户点击该 widget 或其下方文本
- **THEN** 点击落点解析到用户实际点中的行,不因高度图低估而整体下移

#### Scenario: 表格 reveal 后立即点击

- **WHEN** 点击渲染态表格触发 reveal,源码行刚插入 DOM 尚未完成折行测量,用户随即在源码区点击定位
- **THEN** 光标落在被点中的源码行,不偏移到下一行
